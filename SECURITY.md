# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately
through GitHub security advisories:
https://github.com/kulykivska/claude-plugins/security/advisories/new

Include the affected version or commit, the steps to reproduce, and the impact
you expect. You will get a reply as soon as the report has been read.

## Supported versions

Only the latest release on the default branch receives security fixes.
